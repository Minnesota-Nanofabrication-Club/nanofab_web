SETTING UP THE MACHINE DOCUMENTATION SHEET
==========================================

You only do this once.

1. Make a new Google Sheet in the club's Drive. Call it something
   like "Machine documentation".

2. Make five tabs, named EXACTLY (lowercase, no spaces):

       specs   timeline   bom   contributors   references

   The names matter — the sync script looks tabs up by name.

3. For each tab: File -> Import -> Upload -> pick the matching .csv
   from this folder -> Import location: "Replace current sheet".
   That gives you the right column headers, plus one example row you
   can delete or edit.

4. Share -> General access -> "Anyone with the link" -> Viewer.
   (Viewer is enough. The script only reads.)

5. Copy the ID out of the Sheet's URL — the long string between
   /d/ and /edit:

       docs.google.com/spreadsheets/d/<COPY THIS BIT>/edit

6. Put it in hugo.toml, under [params]:

       docsSheetId = "<COPY THIS BIT>"

7. Commit that change. From then on, edit the Sheet and then run the
   "Deploy site to GitHub Pages" workflow from the repo's Actions tab
   (the "Run workflow" button). The site also refreshes on its own
   every six hours.


THE ONE RULE
------------
Every row, on every tab, needs the "machine" column filled in with
that machine's SLUG — the filename in content/machines/ without the
.md. Examples:

       wet-etch        maskless-stepper        rf-magnetron-sputterer

Get it wrong and the row simply won't appear anywhere. The sync
prints a warning naming any slug it doesn't recognise, so check the
workflow log if something's missing.


VALUES THAT MEAN SOMETHING
--------------------------
timeline.status     done | active | planned
bom.status          have | ordered | needed
references.type     datasheet | paper | cad | buildlog | vendor
                    (anything else is grouped under "Other")

bom.unitCost        a plain number: 42.00, not $42.00
                    Anything non-numeric is shown as-is and left out
                    of the total.

timeline rows render IN SHEET ORDER, so drag rows to reorder them.
The date column is optional.


ANYTHING THIS SHEET CAN'T DO
----------------------------
Long background prose lives in the machine's own file in
content/machines/ — a spreadsheet cell is a miserable place to write
paragraphs. Edit those on github.com with the pencil icon.

Architecture diagrams are image files. Put them in
static/images/machines/ and point the machine's front matter at them
with architectureDiagram. See README section 4.15.
